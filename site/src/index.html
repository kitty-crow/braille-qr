How it works

03

Pack

Map each two-by-four dot region into one fixed-width Unicode Braille character.

Distance-gated scanningHollow edges can behave like a “step back to scan” code. That may suit signs, exhibits or installations intended to be read from a viewing distance rather than close-up.

About

A real QR matrix in Unicode Braille.

Braille QR preserves the geometry of a standards-compliant QR code while packing its dots into fixed-width text characters. The same TypeScript core powers the browser generator, command-line tool and embeddable output.

Text first

Copy the result into terminals, messages and documents without exporting an image, or download a standalone HTML file when exact browser rendering matters.

Deliberately small

The project focuses on QR encoding, dot scaling and Braille packing rather than adding an application framework around a compact utility.
